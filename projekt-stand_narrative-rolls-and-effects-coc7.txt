# Changelog

All notable changes to this project are documented in this file.

The format is based on [Keep a Changelog](https://keepachangelog.com/en/1.1.0/), and this project adheres to Semantic Versioning.

## [Unreleased]

### Added
- Standalone Call of Cthulhu 7th Edition companion module for Narrative Rolls and Effects.
- Hook-based adapter registration without cross-module ES imports.
- CoC7-specific result-display and success-level format settings.
- CoC7 bonus and penalty dice as an extension to the core dice visuals.
- CoC7-owned header and details for the core-managed modifier-preparation prompt.
- Difficulty selection during modifier preparation for eligible CoC7 checks.
- Pushed-roll support for opposed checks alongside characteristic, skill, and combined checks according to Call of Cthulhu 7e rules.

### Changed
- Dice-face images, formula visualization, and the shared dice display are provided by the core module; CoC7 prompts now use that shared implementation.
- CoC7 dice tooltips now group percentile units, tens, and bonus/penalty dice into one formula.
- Simplified resolved single-actor check prompts (skill, characteristic, custom, and combined checks) to show the actor name above the check title and display color-coded success levels without duplicate text.

### Fixed
- Kept modifier sliders in preparation and summarized active bonus or penalty dice in roll prompts.
- Pointed bonus and penalty dice visuals to this module's assets and marked chat cards with the CoC7 system identifier.
- Showed failed forced-roll consequences in the normal resolution step instead of a separate phase.
- Restored the expandable skill description in skill-check prompts.

# Narrative Rolls and Effects - Call of Cthulhu 7e

This companion module provides the Call of Cthulhu 7th Edition integration for Narrative Rolls and Effects. It registers a system adapter through the core `nre.registerAdapters` hook and does not import core module files.

## Requirements

- Foundry VTT v14 or later
- The Call of Cthulhu 7th Edition system (`CoC7`)
- Narrative Rolls and Effects

## Installation

Install and enable both Narrative Rolls and Effects and this companion module. The companion module is only active in a CoC7 world.

## Features

- Skill, characteristic, Luck, and Sanity checks
- Combined and opposed rolls
- Multi-phase melee and ranged combat
- System-specific prompt and chat-card layouts
- Configurable result display mode and success-level format
- Roll modifiers, Luck decisions, pushed rolls, and optional consequence automation
- Call of Cthulhu bonus and penalty dice in roll prompts and roll inspection
- Difficulty selection during modifier preparation for eligible checks

## Dice visualization

The core Narrative Rolls and Effects module provides the shared dice visualizer, display template, and dice-face images. This companion module extends the core visuals with the CoC7 bonus and penalty dice; its prompts use the shared core display.

The core also manages the modifier-preparation prompt shell, while this module supplies its header and details.

## Compatibility

This module requires Foundry VTT v14 or later, the Call of Cthulhu 7th Edition system (`CoC7`), and the Narrative Rolls and Effects core module. It registers its adapter through the core `nre.registerAdapters` hook and is only active in a CoC7 world.

let coreApi;

export const MODULE_ID = "narrative-rolls-and-effects";

/** Stores the core API provided during adapter registration for later service access. */
export function setCoreApi(api) {
    coreApi = api;
}

function getCoreService(serviceName) {
    const service = coreApi?.[serviceName];
    if (!service) throw new Error(`Narrative Rolls core service "${serviceName}" is unavailable.`);
    return service;
}

function createServiceFacade(serviceName) {
    // Resolve services lazily so facades can be imported before the core API is available.
    return new Proxy({}, {
        get(_target, property) {
            const service = getCoreService(serviceName);
            const value = service[property];
            return typeof value === "function" ? value.bind(service) : value;
        },
        construct(_target, argumentsList) {
            return Reflect.construct(getCoreService(serviceName), argumentsList);
        }
    });
}

export const SessionStore = createServiceFacade("session");
export const UniversalRollOrchestrator = createServiceFacade("orchestrator");
export const RollVisibilityPolicy = createServiceFacade("visibility");
export const EffectsEngine = createServiceFacade("effects");
export const ActorTargetSelectorApp = createServiceFacade("actorSelector");
export const DiceVisualizer = createServiceFacade("diceVisualizer");

/** Creates a system prompt class through the registered core service. */
export function createPromptClass(definition) {
    return getCoreService("createPromptClass")(definition);
}

/** Extends a core prompt class while keeping prompt construction owned by the core module. */
export function extendPromptClass(baseClass, definition) {
    return getCoreService("extendPromptClass")(baseClass, definition);
}

/** Exposes the core prompt factories in the shape expected by the CoC7 adapter. */
export function getPromptFactory() {
    return {
        createPromptClass: (definition) => createPromptClass(definition),
        extendPromptClass: (baseClass, definition) => extendPromptClass(baseClass, definition)
    };
}

    temporaryInsanity: { color: 0x7b2cbf, secondaryColor: 0x240046, count: 36, durationMs: 2000, gravity: -0.06, spread: 3.2 },
    indefiniteInsanity: { color: 0x4a0e4e, secondaryColor: 0x0d0221, count: 48, durationMs: 2600, gravity: -0.08, spread: 3.8 },

const PREPARATION_DIFFICULTIES = ["regular", "hard", "extreme"];
const DIFFICULTY_PREPARATION_ROLL_TYPES = new Set(["basic", "skill", "combined"]);
const SINGLE_ACTOR_RESOLVED_ROLL_TYPES = new Set(["basic", "skill", "other", "combined"]);

/** Connects CoC7 roll creation, prompts, consequences, and Foundry sheet interactions to the core API. */
export class CoC7Adapter {
    #strategies;

    /** Creates the strategy instances used to resolve each supported roll type. */
    constructor() {
        this.#strategies = Object.freeze({
            basic: new BasicRollStrategy(),
            other: new BasicRollStrategy(),
            skill: new SkillRollStrategy(),
            combined: new CombinedRollStrategy(),
            opposed: new OpposedRollStrategy(),
            sanity: new SanityRollStrategy(),
            combat: new CombatRollStrategy(),
            ranged: new RangedRollStrategy()
        });
    }

    /** Initializes prompts, effect presets, and sheet-click interception after core registration. */
    initialize() {
        initializePromptApps(getPromptFactory());
        this.#registerEffectPresets();
        CoC7Interceptor.register();
    }

    /** Returns the strategy for a roll type, falling back to the standard check strategy. */
    getStrategy(rollType) {
        return this.#strategies[rollType] ?? this.#strategies.basic;
    }

    /** Builds participant data for a new session and initializes post-roll decision fields. */
    buildSessionPayload(type, cfg) {
        const builders = {
            basic: () => CoC7SessionFactory.createBasicOrOther(cfg),
            skill: () => CoC7SessionFactory.createSkillCheck(cfg),
            combined: () => CoC7SessionFactory.createCombined(cfg),
            opposed: () => CoC7SessionFactory.createOpposed(cfg),
            sanity: () => CoC7SessionFactory.createSanityCheck(cfg),
            combat: () => CoC7SessionFactory.createCombat(cfg),
            ranged: () => CoC7SessionFactory.createRanged(cfg)
        };
        const session = builders[type]();
        // Initialize post-roll state consistently for every participant type.
        session.participants = session.participants.map((participant) => ({
            ...participant,
            canPush: participant.canPush ?? true,
            isPushed: false,
            luckDecided: false,
            luckSpent: 0
        }));
        return session;
    }

    /** Supplies the default session state merged into sessions created from the given configuration. */
    getInitialSessionFields(cfg) {
        return {
            canPush: cfg.canPush ?? true,
            combinedMode: cfg.combinedMode ?? "and",
            pushFailurePending: false,
            sanityLossSuccess: cfg.sanityLossSuccess ?? "0",
            sanityLossFailure: cfg.sanityLossFailure ?? "1d6",
            sanityLost: null,
            sanityTriggersBout: false,
            sanityTriggersIndefinite: false,
            sanityPermanentInsanity: false,
            boutDurationRounds: null,
            tempInsanityHours: null,
            combatPhase: cfg.combatPhase ?? "initiator",
            combatType: cfg.combatType ?? "melee",
            weaponName: cfg.weaponName ?? "",
            weaponImg: cfg.weaponImg ?? "",
            damageFormula: cfg.damageFormula ?? "1d6",
            damageBonus: cfg.damageBonus ?? "0",
            tacticalFlags: cfg.tacticalFlags ?? { outnumbered: false, surprised: false, pointBlank: false, cover: false, proneTarget: false },
            defenderReaction: cfg.defenderReaction ?? "dodge",
            defenderWeaponId: cfg.defenderWeaponId ?? "",
            maneuverType: cfg.maneuverType ?? "disarm",
            defenderDodgeValue: cfg.defenderDodgeValue ?? 0,
            defenderFightBackValue: cfg.defenderFightBackValue ?? 0,
            hitWinnerKey: "",
            rawDamage: null,
            armorApplied: 0,
            finalDamage: null,
            majorWoundTriggered: false
        };
    }

    /** Adds CoC7-specific result fields used by the chat-card and prompt templates. */
    enrichSessionForTemplate(session) {
        return CoC7SessionFactory.enrichForTemplate(session);
    }

    /** Returns the actor's available checks for use in the roll-request composer. */
    collectActorChecks(actor, options = {}) {
        return CoC7SessionFactory.collectActorChecks(actor, options);
    }

    /** Returns the localized label for a CoC7 roll type. */
    getRollTypeLabel(rollType) {
        return game.i18n.localize(`ROE_COC7.RollSession.Types.${rollType}`);
    }

    /** Returns the Handlebars template used to render a CoC7 session chat card. */
    getChatCardTemplate() {
        return "modules/narrative-rolls-and-effects-coc7/templates/chat/coc7-session-card.hbs";
    }

    /** Defines the roll-type tabs displayed by the request composer. */
    getRequestComposerTabs() {
        const tabDefinitions = [
            ["skill", "fa-dice-d20"],
            ["sanity", "fa-brain"],
            ["combined", "fa-code-merge"],
            ["opposed", "fa-scale-balanced"],
            ["other", "fa-cubes"]
        ];
        return tabDefinitions.map((definition) => this.#createRequestTab(...definition));
    }

    /** Returns the Handlebars template used for CoC7 request fields. */
    getRequestComposerTemplate() {
        return "modules/narrative-rolls-and-effects-coc7/templates/dialogs/coc7-request-fields.hbs";
    }

    /** Builds request-form context, including check choices for the supplied actors. */
    getRequestComposerContext(rollType, { actorA, actorB }) {
        return {
            rollType,
            isSkill: rollType === "skill",
            isSanity: rollType === "sanity",
            isCombined: rollType === "combined",
            isOpposed: rollType === "opposed",
            isOther: rollType === "other",
            checksA: actorA ? this.collectActorChecks(actorA, { includeSpecial: rollType === "skill" }) : [],
            checksB: actorB ? this.collectActorChecks(actorB, { includeSpecial: false }) : []
        };
    }

    /** Reads the request form and starts the matching roll session; returns false if its primary actor is missing. */
    async dispatchRequestComposer(rollType, form, { prepareModifiers }) {
        const actorA = game.actors.get(form.querySelector("select[name='actorA']")?.value);
        if (!actorA) return false;

        if (rollType === "skill") {
            await this.#dispatchSkillRequest(actorA, form, prepareModifiers);
        } else if (rollType === "sanity") {
            await this.#dispatchSanityRequest(actorA, form, prepareModifiers);
        } else if (rollType === "combined") {
            await this.#dispatchCombinedRequest(actorA, form, prepareModifiers);
        } else if (rollType === "opposed") {
            await this.#dispatchOpposedRequest(actorA, form, prepareModifiers);
        } else if (rollType === "other") {
            await this.#dispatchOtherRequest(actorA, form, prepareModifiers);
        } else {
            throw new Error(`Unknown Call of Cthulhu request type "${rollType}".`);
        }
        return true;
    }

    /** Verifies that a submitted roll uses the modifier dice allowed by its session state. */
    validateSubmittedRoll(session, participant, rollData) {
        if (session.rollType === "other" || participant.key === "damage") return true;
        if (participant.key === "defender" && (session.rollType === "ranged" || session.defenderReaction === "none")) return true;

        // Recompute contextual dice modifiers so submitted results match the session flags.
        let expected = Number(participant.modifierDice ?? 0);
        if (session.rollType === "combat" && participant.key === "attacker") {
            const f = session.tacticalFlags ?? {};
            expected += Number(Boolean(f.outnumbered)) + Number(Boolean(f.surprised)) +
                Number(Boolean(f.pointBlank)) + Number(Boolean(f.proneTarget)) - Number(Boolean(f.cover));
        }
        if (session.rollType === "ranged" && participant.key === "attacker") {
            if (session.participants.find((e) => e.key === "defender")?.tookCover) expected--;
        }
        return Number(rollData.modifierDice ?? 0) === Math.clamp(expected, -2, 2);
    }

    /** Rolls and packages a participant's pushed check for submission by the core orchestrator. */
    async executePushRoll(session, participantKey) {
        if (!CoC7CheckResolver.canPush(session, participantKey)) return null;
        const participant = session.participants.find((p) => p.key === participantKey);
        const modifierDice = Number(participant.modifierDice ?? 0);
        const roll = await new Roll(CoC7CheckResolver.buildRollFormula(modifierDice)).evaluate();
        return {
            total: roll.total === 0 ? 100 : roll.total,
            modifierDice,
            rollMode: RollVisibilityPolicy.getCurrentRollMode(),
            rollerUserId: game.user.id,
            rollBreakdown: CoC7CheckResolver.buildBreakdown(roll, 0, "", { modifierDice })
        };
    }
    /** Applies session patches and validates CoC7-specific resets and defender-reaction changes. */
    transformSessionPatch(session, patch) {
        if (patch.resetCombatPhase || patch.resetSanityPhase) {
            if (session.consequencesApplied) return session;
            // Rewinds clear the roll result as well as post-roll choices tied to it.
            const clear = {
                hasRolled: false, total: null, successLevel: "", isSuccess: false,
                isPushed: false, luckDecided: false, luckSpent: 0, rollBreakdown: null
            };
            if (patch.resetCombatPhase && session.rollType === "combat") {
                const key = { initiator: "attacker", opponent: "defender" }[patch.resetCombatPhase];
                if (!key || !session.participants.find((p) => p.key === key)?.hasRolled) return session;
                return {
                    ...session,
                    participants: session.participants.filter((p) => p.key !== "damage")
                        .map((p) => p.key === key ? { ...p, ...clear } : p),
                    combatPhase: "initiator", phase: "rolling", hitWinnerKey: "", rawDamage: null,
                    armorApplied: 0, finalDamage: null, majorWoundTriggered: false,
                    hasPendingConsequences: false, winnerKey: "", outcomeHeadline: ""
                };
            }
            if (patch.resetSanityPhase && session.rollType === "sanity") {
                const key = { check: "p0", insight: "insanityInt" }[patch.resetSanityPhase];
                if (!key || !session.participants.find((p) => p.key === key)?.hasRolled) return session;
                const participants = session.participants.filter((p) => key !== "p0" || p.key !== "insanityInt")
                    .map((p) => p.key === key ? { ...p, ...clear } : p);
                const sanity = key === "p0"
                    ? {
                        sanityLost: null, sanityTriggersBout: false, sanityTriggersIndefinite: false,
                        sanityPermanentInsanity: false, boutDurationRounds: null, tempInsanityHours: null,
                        hasPendingConsequences: false
                    }
                    : { boutDurationRounds: null, tempInsanityHours: null, hasPendingConsequences: true };
                return { ...session, ...sanity, participants, phase: "rolling", winnerKey: "", outcomeHeadline: "" };
            }
            return session;
        }
        if (session.rollType === "combat" && ("defenderReaction" in patch || "reactionDetail" in patch)) {
            const defender = session.participants.find((p) => p.key === "defender");
            if (!defender || defender.hasRolled) return session;
            if ("defenderReaction" in patch) {
                const reaction = patch.defenderReaction;
                if (!["dodge", "fightBack", "maneuver", "none"].includes(reaction)) return session;
                const targetValue = reaction === "dodge" ? session.defenderDodgeValue
                    : reaction === "fightBack" || reaction === "maneuver" ? session.defenderFightBackValue : 0;
                return {
                    ...session, defenderReaction: reaction,
                    participants: session.participants.map((p) => p.key === "defender"
                        ? {
                            ...p, label: game.i18n.localize(`ROE_COC7.Combat.DefenseModes.${reaction}`), targetValue,
                            hasRolled: false, total: null, successLevel: "", isSuccess: false
                        }
                        : p)
                };
            }
            const detail = patch.reactionDetail;
            if (session.defenderReaction === "maneuver") {
                return ["disarm", "grapple", "knockdown", "push"].includes(detail)
                    ? { ...session, maneuverType: detail } : session;
            }
            if (session.defenderReaction === "fightBack") {
                const actor = SessionStore.resolveActor(defender);
                const weapon = detail === "unarmed" ? null : actor?.items.get(detail);
                if (!actor || (detail !== "unarmed" && weapon?.type !== "weapon")) return session;
                const skill = CoC7DataMapper.findActorSkill(actor, weapon
                    ? weapon.system?.skill?.main
                    : { name: game.i18n.localize("ROE_COC7.SkillList.FightingBrawl") });
                const label = weapon
                    ? `${weapon.name} (${skill?.name || game.i18n.localize("ROE_COC7.Combat.DefenseTabs.fightBack")})`
                    : game.i18n.localize("ROE_COC7.Combat.DefenseModes.fightBack");
                return {
                    ...session, defenderWeaponId: detail,
                    participants: session.participants.map((p) => p.key === "defender"
                        ? {
                            ...p, itemId: weapon?.id ?? "", label,
                            targetValue: skill ? CoC7DataMapper.getSkillValue(skill) : session.defenderFightBackValue
                        }
                        : p)
                };
            }
            return session;
        }
        return { ...session, ...patch };
    }
    /**
    * Handles a participant's post-roll choice and returns the updated session and finalization decision.
    * Called by the core orchestrator with a supported action ID and its action payload.
    */
    async handlePostRollAction(session, participantKey, actionId, payload) {
        if (actionId === "spendLuck") {
            const target = session.participants.find((p) => p.key === participantKey);
            if (!target || target.isPushed) return null;
            const actor = SessionStore.resolveActor(target);
            const currentLuck = CoC7DataMapper.getResource(actor, "luck")?.value ?? 0;
            const cost = Number(payload.cost);
            if (!actor || currentLuck < cost) return null;
            const remainingLuck = currentLuck - cost;
            await actor.update({ "system.attribs.lck.value": remainingLuck });
            const rank = CoC7CheckResolver.LEVEL_RANK;
            const isSuccess = (rank[payload.newLevel] ?? 0) >= (rank[session.difficulty] ?? 2);
            const canUpgradeMore = this.#canUpgradeFurther(target.total, target.targetValue, payload.newLevel, remainingLuck);
            const participants = session.participants.map((p) =>
                p.key === participantKey
                    ? { ...p, successLevel: payload.newLevel, isSuccess, luckSpent: (p.luckSpent ?? 0) + cost, luckDecided: !canUpgradeMore }
                    : p
            );
            return { session: { ...session, participants }, finalize: true };
        }
        if (actionId === "declineLuck") {
            const participants = session.participants.map((p) =>
                p.key === participantKey ? { ...p, luckDecided: true } : p
            );
            return { session: { ...session, participants }, finalize: false };
        }
        if (actionId === "pushRoll") {
            const participants = CoC7CheckResolver.buildPushedParticipants(session, participantKey, payload.rollData);
            if (!participants) return null;
            return { session: { ...session, participants }, finalize: true };
        }
        return null;
    }
    /** Calculates which Luck and push actions the current user may take for a rolled participant. */
    evaluateParticipantOptions(participant, session, isDelegatedToPlayer) {
        if (!participant?.hasRolled || session.isResolved || session.rollType === "other") {
            return { canSpendLuck: false, luckCost: 0, luckTargetLevel: "", luckTargetLabel: "", canPush: false, hasPendingAction: false, isDelegatedToPlayer };
        }
        const actor = SessionStore.resolveActor(participant);
        if (!actor || (!game.user.isGM && !actor.isOwner)) {
            return { canSpendLuck: false, luckCost: 0, luckTargetLevel: "", luckTargetLabel: "", canPush: false, hasPendingAction: false, isDelegatedToPlayer };
        }
        const level = participant.successLevel;
        const isPushed = Boolean(participant.isPushed);
        const availableLuck = CoC7DataMapper.getResource(actor, "luck")?.value ?? 0;
        let luckCost = 0;
        let luckTargetLevel = "";
        // Luck can improve a failure to the required level or advance an allowed success by one level.
        if (!participant.luckDecided && !isPushed && level !== "fumble" && level !== "critical" && availableLuck > 0) {
            const allowImprove = this.#isLuckImprovementAllowed();
            let desiredLevel = "";
            if (!participant.isSuccess) desiredLevel = session.difficulty || "regular";
            else if (allowImprove) {
                if (level === "regular") desiredLevel = "hard";
                else if (level === "hard") desiredLevel = "extreme";
            }
            if (desiredLevel) {
                const threshold = this.getDifficultyThreshold(participant.targetValue, desiredLevel);
                const needed = participant.total - threshold;
                if (needed > 0 && needed <= availableLuck) {
                    luckCost = needed;
                    luckTargetLevel = desiredLevel;
                }
            }
        }
        const canPush = CoC7CheckResolver.canPush(session, participant.key);
        const canSpendLuck = luckCost > 0;
        return {
            canSpendLuck,
            luckCost,
            luckTargetLevel,
            luckTargetLabel: luckTargetLevel ? game.i18n.localize(`ROE_COC7.SuccessLevels.${luckTargetLevel}`) : "",
            canPush,
            hasPendingAction: canSpendLuck || canPush,
            isDelegatedToPlayer
        };
    }
    /** Returns the participants shown in the modifier-preparation phase, or an empty list otherwise. */
    buildPreparationParticipants(session) {
        if (!session?.isPreparingModifiers || session.rollType === "other") return [];
        let participants = session.participants ?? [];
        if (session.rollType === "combined") participants = participants.slice(0, 1);
        if (session.rollType === "ranged") participants = participants.filter((participant) => participant.key === "attacker");
        return participants.map((participant) => ({
            ...participant,
            preparationLabel: session.rollType === "combined" ? session.title : participant.label,
            modifierDisplay: this.#formatModifierLabel(participant.modifierDice ?? 0)
        }));
    }
    /** Returns the tactical modifier controls shown while preparing a combat roll. */
    buildPreparationTactics(session) {
        if (!session?.isPreparingModifiers || session.rollType !== "combat") return [];
        const labels = { outnumbered: "Outnumbered", surprised: "Surprised", proneTarget: "ProneTarget" };
        return Object.entries(labels).map(([key, label]) => ({
            key,
            label: game.i18n.localize(`ROE_COC7.Combat.Tactical.${label}`),
            active: Boolean(session.tacticalFlags?.[key])
        }));
    }
    /** Formats a participant's resolved result for the session summary. */
    formatResolvedParticipant(participant, session) {
        if (session.rollType === "ranged" && participant.key === "defender") {
            return game.i18n.localize(participant.tookCover ? "ROE_COC7.Ranged.CoverTaken" : "ROE_COC7.Ranged.NoCover");
        }
        if (participant.total === null) return game.i18n.localize("ROE_COC7.Combat.DefenseTabs.none");
        if (session.rollType === "other" || participant.key === "damage") return String(participant.total ?? "");
        return this.formatRollOutcome(participant);
    }
    /** Builds a permission-aware result badge for a participant in a chat card. */
    formatParticipantBadge(participant, session, permissions) {
        if (!permissions.canViewRoll) {
            return { text: game.i18n.localize("ROE.RollSession.HiddenRoll"), className: "pending-badge" };
        }
        if (!permissions.showDetails) {
            return { text: game.i18n.localize("ROE_COC7.Combat.Card.HiddenUntilOwnRoll"), className: "pending-badge" };
        }
        if (participant.total === null) {
            return { text: game.i18n.localize("ROE_COC7.Combat.DefenseTabs.none"), className: "pending-badge" };
        }
        if (participant.key === "damage") {
            return { text: `${participant.total} (${participant.diceFormula})` };
        }
        if (session.rollType === "other") return { text: String(participant.total) };
        const allowNumbers = permissions.isGM || Boolean(permissions.actor?.testUserPermission(game.user, "OBSERVER"));
        return {
            text: this.formatRollOutcome({
                total: participant.total,
                targetValue: participant.targetValue,
                successLevel: participant.successLevel,
                allowNumbers
            })
        };
    }
    /** Adds push-failure warning, visibility, and resolved single-actor fields to a prompt's prepared context. */
    preparePromptContext(prompt, session, context) {
        const pushedParticipants = (session?.participants ?? []).filter((participant) => participant.isPushed);
        const base = {
            ...context,
            showPushFailureWarning: Boolean(game.user.isGM && session?.pushFailurePending),
            canViewPushFailure: pushedParticipants.length > 0 && pushedParticipants.every((participant) =>
                RollVisibilityPolicy.canViewParticipantRoll(participant, session)
            )
        };
        if (!session?.isResolved || !SINGLE_ACTOR_RESOLVED_ROLL_TYPES.has(session.rollType)) return base;
        return { ...base, ...this.#buildResolvedSingleActorContext(session) };
    }

    /** Returns the registered Handlebars partials to include during modifier preparation. */
    getModifierPreparationPartials(session) {
        if (!session?.isPreparingModifiers) return {};
        return {
            header: "roeCocModifierPreparationHeader",
            details: "roeCocModifierPreparationDetails"
        };
    }

    /** Returns the registered Handlebars partials to include when displaying resolved single-actor checks. */
    getResolvedResultPartials(session) {
        if (!session?.isResolved || !SINGLE_ACTOR_RESOLVED_ROLL_TYPES.has(session.rollType)) return {};
        return {
            header: "roeCocResolvedSingleHeader",
            body: "roeCocResolvedSingleBody"
        };
    }

    /** Returns the difficulty choices allowed in the current modifier-preparation phase. */
    buildPreparationDifficulties(session) {
        if (
            !session?.isPreparingModifiers ||
            session.canChangeDifficulty === false ||
            !DIFFICULTY_PREPARATION_ROLL_TYPES.has(session.rollType)
        ) return [];
        return PREPARATION_DIFFICULTIES.map((difficulty) => ({
            value: difficulty,
            label: game.i18n.localize(`ROE_COC7.Difficulty.${difficulty.capitalize()}`),
            selected: session.difficulty === difficulty
        }));
    }
    /** Identifies participants whose modifier dice change together for the selected roll type. */
    getModifierParticipantKeys(session, participantKey) {
        return session.rollType === "combined"
            ? session.participants.map((participant) => participant.key)
            : [participantKey];
    }
    /** Routes a prompt action to the corresponding Luck, push, or preparation handler. */
    handlePromptAction(prompt, actionName, event, target) {
        const handlers = {
            spendLuck: () => this.#spendLuck(prompt, target),
            declineLuck: () => this.#declineLuck(prompt, target),
            pushRoll: () => this.#pushRoll(prompt, target),
            togglePreparedTactical: () => this.#togglePreparedTactical(prompt, target),
            setPreparedDifficulty: () => this.#setPreparedDifficulty(prompt, target)
        };
        const handler = handlers[actionName];
        if (handler) return handler();
        return undefined;
    }
    /** Converts a base target to the CoC7 target number for regular, hard, or extreme difficulty. */
    getDifficultyThreshold(target, difficulty) {
        if (difficulty === "hard") return Math.floor(target / 2);
        if (difficulty === "extreme") return Math.floor(target / 5);
        return target;
    }
    /** Delegates roll-outcome formatting so adapter consumers use the configured display style. */
    formatRollOutcome(params) {
        return CoC7ResultFormatter.formatRollOutcome(params);
    }
    /** Returns the localized display text for a success level, or an empty string when absent. */
    formatSuccessLevel(level) {
        return level ? game.i18n.localize(`ROE_COC7.SuccessLevels.${level}`) : "";
    }
    /** Renders regular, hard, and extreme target numbers for the roll-inspection view. */
    formatInspectionThresholds(breakdown) {
        if (breakdown.targetValue <= 0) return "";
        return `<div class="inspect-thresholds"> <span>${game.i18n.localize("ROE_COC7.Difficulty.Regular")}: <strong>${breakdown.targetValue}</strong></span> <span>${game.i18n.localize("ROE_COC7.Difficulty.Hard")}: <strong>${breakdown.hardThreshold}</strong></span> <span>${game.i18n.localize("ROE_COC7.Difficulty.Extreme")}: <strong>${breakdown.extremeThreshold}</strong></span> </div>`;
    }
    /** Converts dice-visualizer entries into a concise, localized formula label. */
    formatDiceFormulaLabel(diceArray) {
        const counts = { units: 0, tens: 0, bonus: 0, penalty: 0 };

/** Implements percentile check resolution, roll construction, and pushed-roll validation. */
export class CoC7CheckResolver {
    static LEVEL_RANK = Object.freeze({
        fumble: 0,
        failure: 1,
        regular: 2,
        hard: 3,
        extreme: 4,
        critical: 5
    });

    /** Returns the CoC 7e success level for a roll against a target value. */
    static evaluateResult(rollTotal, targetValue) {
        if (rollTotal === 1) return "critical";
        targetValue = Number(targetValue);
        const fumbleThreshold = targetValue < 50 ? 96 : 100;
        if (rollTotal >= fumbleThreshold) return "fumble";
        if (rollTotal <= Math.floor(targetValue / 5)) return "extreme";
        if (rollTotal <= Math.floor(targetValue / 2)) return "hard";
        if (rollTotal <= targetValue) return "regular";
        return "failure";
    }

    /**
     * Builds a percentile formula; bonus or penalty dice add tens dice and keep the
     * lowest or highest tens result respectively.
     */
    static buildRollFormula(modifierDice = 0) {
        const extraTens = Math.abs(modifierDice);
        if (extraTens === 0) return "1d100";
        const tensKeep = modifierDice > 0 ? "kl" : "kh";
        return `((${1 + extraTens}d10${tensKeep} - 1) * 10) + (1d10 - 1)`;
    }

    static buildBreakdown(roll, targetValue = 0, successLevel = "", modifiers = null) {
        const diceTerms = [];
        for (const term of roll.terms ?? []) {
            if (term instanceof foundry.dice.terms.Die) {
                diceTerms.push({
                    expression: `${term.number}d${term.faces}`,
                    results: (term.results ?? []).map((r) => ({ value: r.result, active: r.active !== false && !r.discarded }))
                });
            }
        }
        const target = Number(targetValue ?? 0);
        return {
            formula: roll.formula,
            total: roll.total === 0 && roll.formula.includes("100") ? 100 : roll.total,
            targetValue: target,
            hardThreshold: target > 0 ? Math.floor(target / 2) : 0,
            extremeThreshold: target > 0 ? Math.floor(target / 5) : 0,
            successLevel,
            ...(modifiers ? { modifierDice: Number(modifiers.modifierDice ?? 0), tacticalFlags: modifiers.tacticalFlags ?? [] } : {}),
            diceTerms
        };
    }

    /** Checks whether the session and selected participant are eligible for a push. */
    static canPush(state, participantKey) {
        if (!state || state.isResolved || state.isPreparingModifiers || state.canPush === false) return false;
        if (!["basic", "skill", "combined", "opposed"].includes(state.rollType)) return false;
        const participants = state.participants ?? [];
        const participant = participants.find((e) => e.key === participantKey);
        if (!participant?.hasRolled || participant.isPushed || participant.canPush === false || participant.successLevel === "fumble") return false;

        if (state.rollType === "opposed") {
            if (participants.length < 2 || participants.some((e) => !e.hasRolled)) return false;
            return this.#determineOpposedWinnerKey(participants) !== participantKey;
        }

        if (state.rollType !== "combined") return !participant.isSuccess;
        if (participants.length < 2 || participants.some((e) => !e.hasRolled || e.isPushed || e.canPush === false || e.successLevel === "fumble")) return false;
        const passed = state.combinedMode === "or" ? participants.some((e) => e.isSuccess) : participants.every((e) => e.isSuccess);
        return !passed;
    }

    static #determineOpposedWinnerKey(participants) {
        const successful = participants.filter((p) => (this.LEVEL_RANK[p.successLevel] ?? 0) >= this.LEVEL_RANK.regular);
        if (successful.length === 0) return "";
        successful.sort((a, b) => {
            const rankDiff = (this.LEVEL_RANK[b.successLevel] ?? 0) - (this.LEVEL_RANK[a.successLevel] ?? 0);
            if (rankDiff !== 0) return rankDiff;
            return Number(b.targetValue ?? 0) - Number(a.targetValue ?? 0);
        });
        return successful[0].key;
    }

    /** Applies a validated pushed result to the participant or combined-check participants. */
    static buildPushedParticipants(state, participantKey, rollData) {
        if (!this.canPush(state, participantKey)) return null;
        const total = Number(rollData.total);
        if (!Number.isInteger(total) || total < 1 || total > 100) return null;
        const targets = state.rollType === "combined" ? state.participants : state.participants.filter((e) => e.key === participantKey);
        const modifierDice = Number(targets[0]?.modifierDice ?? 0);
        if (Number(rollData.modifierDice ?? 0) !== modifierDice) return null;

        const keys = new Set(targets.map((e) => e.key));
        const requiredRank = this.LEVEL_RANK[state.difficulty] ?? 2;

        return state.participants.map((p) => {
            if (!keys.has(p.key)) return p;
            const target = Number(p.targetValue ?? 0);
            const successLevel = this.evaluateResult(total, target);
            return {
                ...p,
                previousRoll: { total: p.total, successLevel: p.successLevel, isSuccess: p.isSuccess, rollBreakdown: p.rollBreakdown ?? null },
                total,
                successLevel,
                isSuccess: (this.LEVEL_RANK[successLevel] ?? 0) >= requiredRank,
                isPushed: true,
                luckDecided: true,
                rollMode: rollData.rollMode || state.rollMode || "publicroll",
                rollerUserId: rollData.rollerUserId || "",
                rollBreakdown: { ...rollData.rollBreakdown, total, targetValue: target, successLevel, modifierDice }
            };
        });
    }

    static #resolveSheetActor(sheetEl) {

            if (doc) return doc.actor ?? doc;
        }

        if (foundry.applications?.instances) {
            for (const app of foundry.applications.instances.values()) {
                if (app.element === sheetEl || app.element?.contains(sheetEl)) {

    static #resolveClickedItem(actor, trigger) {

        if (itemId) {
            const byId = actor.items.get(itemId);
            if (byId) return byId;
        }
        if (itemEl?.dataset.uuid) {
            const doc = fromUuidSync(itemEl.dataset.uuid);
            if (doc?.parent === actor) return doc;
        }

        const tooltipName = (trigger.dataset.nameTooltip || trigger.textContent || "").trim().toLowerCase();

        }
        if (trigger.classList.contains("weapon-name")) {
            return actor.items.find((i) => i.type === "weapon" && i.name.toLowerCase() === tooltipName) ?? null;
        }
        return actor.items.find((i) => (i.type === "skill" || i.type === "weapon") && i.name.toLowerCase() === tooltipName) ?? null;

import { COC7_MODULE_ID } from "./coc7-settings.mjs";

/** Formats check levels and roll outcomes according to the world's display settings. */
export class CoC7ResultFormatter {
    static SYMBOL_MAP = Object.freeze({
        critical: "***!",
        extreme: "***",
        hard: "**",
        regular: "*",
        failure: "-",
        fumble: "---"
    });

    static formatSuccessLevel(successLevel) {
        if (!successLevel) return "";
        const format = game.settings?.get(COC7_MODULE_ID, "successLevelFormat") || "text";
        if (format === "symbols") return this.SYMBOL_MAP[successLevel] ?? "";
        return game.i18n.localize(`ROE_COC7.SuccessLevels.${successLevel}`);
    }

    static formatRollOutcome({ total, targetValue, successLevel, allowNumbers = true }) {
        const mode = game.settings?.get(COC7_MODULE_ID, "resultDisplayMode") || "both";
        const levelText = this.formatSuccessLevel(successLevel);
        if (!allowNumbers || mode === "level") return levelText || String(total ?? "");
        const numberPart = targetValue ? `${total} vs. ${targetValue}` : `${total}`;
        if (mode === "numbers" || !levelText) return numberPart;
        return `${numberPart} • ${levelText}`;
    }
}

            const intValue = Number(actor.system?.characteristics?.int?.value ?? 50);
            return [

                    ...SessionStore.buildParticipant(
                        "insanityInt",
                        actor,
                        game.i18n.localize("ROE_COC7.Sanity.TemporaryInsanityIntCheck"),
                        intValue
                    ),
                    diceFormula: "1d100",
                    isFollowUp: true
                }
            ];
        }

        if (hasConsequences) {
            if (autoApply) {
                await this.applyConsequences(state);
                state.consequencesApplied = true;
                state.hasPendingConsequences = false;
            } else {
                state.hasPendingConsequences = true;
            }
        } else {
            state.consequencesApplied = true;
            state.hasPendingConsequences = false;
        }

        return [];
    }

    /** @override */
    async applyConsequences(state) {
        const sanRoll = state.participants?.find((p) => p.key === "p0") ?? state.participants?.at(0);
        if (!sanRoll) return;

        const actor =
            SessionStore.resolveActor(sanRoll);
        if (!actor) return;

        const lost = Number(state.sanityLost ?? 0);
        const sanResource = CoC7DataMapper.getResource(actor, "sanity") ?? {};
        const currentSan = Number(sanResource.value ?? 0);
        const previousDailyLoss = Number(sanResource.dailyLoss ?? 0);

        if (lost > 0) {
            const updates = {
                "system.attribs.san.value": Math.max(0, currentSan - lost),
                "system.attribs.san.dailyLoss": previousDailyLoss + lost
            };
            await actor.update(updates);
        }

        const intRoll = state.participants?.find((p) => p.key === "insanityInt");
        if (state.sanityPermanentInsanity || state.sanityTriggersIndefinite) {
            await CoC7DataMapper.setCondition(actor, "indefiniteInsanity", true);
        } else if (intRoll?.hasRolled && intRoll?.isSuccess) {
            await CoC7DataMapper.setCondition(actor, "temporaryInsanity", true);
        }
    }

    /** @override */
    evaluateResolution(state) {
        const base = super.evaluateResolution(state);
        const { sanitySummaryText } = CoC7SessionFactory.enrichForTemplate(state);

        return {
            winnerKey: base.winnerKey,
            outcomeHeadline: sanitySummaryText || base.outcomeHeadline
        };
    }
